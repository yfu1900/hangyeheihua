## 3. 常用行业简称和业务黑话

这些词不是严格的同义词，但机器人需要理解其业务含义。

| 黑话或写法 | 建议解释 | 自动处理边界 |
|---|---|---|
| 冷 | 冷轧类材料的简称。 | 不得因此与冷硬或冷成形合并。 |
| 热 | 热轧类材料的简称。 | 只有在品名、材质或报价规格语境中才能按材料类别理解。 |
| `厚度*宽度*C` | `C`表示整卷，例如`1.0*1000*C`。 | 只在规格末位使用此解释。 |
| `厚度*宽度` | 当前贸易业务中通常表示不带定尺长度的半成品规格。 | 这是订单识别口径，不是所有行业场景的通用定义。 |
| `厚度+材质+宽度` | 指定材料状态的半成品规格，例如`1.0冷硬*150`。 | 必须同时保留厚度、材质和宽度，不能只按其中一项匹配。 |
| `+N` | 在基础价格上加价。 | 不能把`+N`单独当作完整销售价；币种和计价单位缺失时保留原文。 |
| `-N` | 在基础价格上减价。 | 必须绑定基础价格和对应规格，不能脱离上下文计算。 |
| 四位数裸价 | 报价语境中通常表示一个完整价格。 | 必须结合被回复订单判断它是原卷价、成品价还是其他价格。 |
| 卷价、原卷价 | 加工母卷的基础单价。 | 与加工费、包装费、成品销售价分开。 |
| 丝 | 板材厚度差的行业单位，`1丝=0.01mm`。 | 仅用于厚度和公差语境。 |
| 薄N个丝 | 实际厚度比名义厚度小`N×0.01mm`。 | 不能脱离名义厚度单独解释。 |
| 两位小数厚度对应一位小数名义厚度 | 报价厚度低于名义厚度且相差`0.01–0.05mm`时，可作为同档厚度候选。 | 只用于报价候选匹配；不是全局等值替换，仍须核对材质、宽度和订单。 |
| 分条 | 沿卷材长度方向纵向裁成目标宽度的窄条。 | 规格通常以`厚度*宽度`和“条”计数。 |
| 分转平 | 先分条，再平直/定尺剪板。 | 不能简化成单纯“分条”或单纯“平直”。 |
| 直平 | 原卷直接平直、定尺，不先分条。 | 与“分转平”工艺路径不同。 |
| 分段 | 把分条后的成品分成多个较小卷段。 | 应结合单卷重量、外径等要求。 |
| 一段过 | 不分段，连续成一个卷段。 | 已有明确同义证据。 |
| 双飞 | 特定分条排刀或生产方式。 | 现有证据不足以自动展开具体设备含义，须继续确认。 |
| 自己配刀 | 需要自行安排分条宽度组合或排刀方案。 | 当前只有上下文证据，保留为中等置信度术语。 |
| 开、开料、开出 | 用指定原卷加工出目标规格和重量。 | “开N吨”通常是计划加工量，不一定等于最终成品磅重。 |
| 配料、配出、配到 | 选择适当原卷并计算能够加工出的目标重量。 | 不能把估算配出重量当作实际验收重量。 |
| 要整卷、只能整卷 | 对应规格不能按小数量拆卖或加工，需要采购或使用整卷。 | 必须保留它是采购要求还是加工限制的上下文。 |
| 整卷外采 | 从外部采购整卷材料，而不是使用内部现有原卷加工。 | 不等同于外采成品。 |
| 整卷用完 | 原卷全部投入本单加工，不留回卷。 | 仍需用实际用料和成品重量核对。 |
| 余下回卷 | 剩余原料重新成卷，不做预加工库存。 | 回卷包装方式必须另有明确说明。 |
| 余下开预加工 | 剩余材料加工成常备库存规格。 | 属于预加工，不等同于回卷。 |
| 不开预加工 | 剩余部分不转成预加工库存。 | 可能回卷或采用其他处理，必须结合上下文。 |
| 外采成品 | 不使用自有原卷加工，直接从外部采购目标成品。 | 应以外部采购和仓储资料为准，不能用内部加工资料替代。 |
| 在途货 | 已采购或已确定资源、尚未正式入仓的材料。 | 不能当作当前现货库存。 |
| 低消N吨 | 最低加工量或最低计价量为N吨。 | 现有资料未统一区分“最低投料量”和“最低收费量”，应保留原文。 |
| 没货 | 当前没有可供报价或加工的材料资源。 | 属于资源状态，不是价格回复。 |
| 规格停产 | 对应规格已经停止生产或供应。 | 属于供应状态，不是价格回复。 |
| 稍后报、明天报 | 当前报价需要延后。 | 属于延迟状态，不代表已经获得报价。 |
| 打外径 | 按卷外径要求分卷、成卷。 | 应同时保留具体外径限制。 |
| 上木架、落木架、放木架 | 将成品放置在木架上交付。 | 木架是否自带、是否另计必须分别识别。 |
| 合打一包 | 多个规格或多组成品合并包装成一包。 | 不代表规格、重量或仓储号可以合并。 |
| 密封包 | 使用密封包装方式。 | 与简包不同，不能互相替代。 |
| 80锌 | 镀锌层级的行业简称。 | 现有资料不足以确认其完整计量口径，禁止擅自展开。 |
| `负公差N个C` | 很可能表示“负公差N丝”。 | 现有资料能确认“丝”的单位含义，但不能证明这里的字母`C`一定等于“丝”，必须人工确认。 |
| 成品名义厚度进位 | 当前验收规则只对两位小数且末位为7或9的成品厚度增加`0.01mm`。 | 例如末位为8时不适用；原料和回卷必须保留原始厚度。 |
| `尾N/厚度/宽度` | 依次表示头尾板重量N kg、实测厚度和实测宽度。 | 只有“尾+明确数字”或其他受支持格式才能派生，不能猜测裸数字。 |
| `整卷重量/厚度x宽度/尾重` | 依次表示整卷重量、实测厚度与宽度、头尾板重量。 | 第一段不能误当成废料重量。 |
| 条 | 分条后的条带/小卷数量。 | 不等同于平板的“张”或包装的“件”。 |
| 张、件 | 平直/定尺板数量。 | 与“条”对应不同加工区段。 |

## 4. 明确不能合并的近似词

| 容易误合并的词 | 实际区别 |
|---|---|
| 冷板、冷硬、冷成形 | 是不同产品状态/品类，不能统一成“冷板”。 |
| 普板、冷板 | 是不同材料类别，不能视为同义词。 |
| 自由边、边丝 | 自由边是可利用余料；边丝通常是废料，验收分类不同。 |
| 简包、密封包 | 包装方式和费用口径不同。 |
| 回卷、预加工 | 回卷保留卷材；预加工是把余料加工成库存成品。 |
| 原卷价、`+N/-N`价格调整、成品价 | 分别是材料基价、价格增减量和最终成品价格。 |
| 现货、在途货 | 现货当前可用；在途货尚未正式入仓。 |
| 外采成品、整卷外采 | 前者采购目标成品，后者采购整卷原料。 |
| 分条、分转平、直平 | 三种不同加工路径，不能只按“都是加工”合并。 |
| SPCC、SPCC麻面、SPCC光面 | 目标系统输出可能去掉表面描述，但原始业务资料中的表面差异必须保留。 |
| 近似厚度、完全相同厚度 | 近似厚度只能作为报价匹配候选，不能全局当作相同规格。 |

## 5. 特别风险：字母 `C` 的语义重载

`C`至少存在两种完全不同的可能含义：

1. 规格末位：`厚度*宽度*C`中的`C`表示整卷。
2. 公差描述：`负公差N个C`中的`C`可能是“丝”的输入或OCR写法。

因此禁止对字母`C`做全局替换；必须先判断它位于规格结构还是自然语言公差描述中。

## 6. 词典数据结构建议

后续若将本词典用于程序，可为每组黑话保存以下字段：

```json
{
  "canonical": "冷板",
  "aliases": ["冷卷", "冷轧", "冷卷板", "冷轧卷板"],
  "scope": "product_name",
  "confidence": "high",
  "preserveOriginal": true,
  "constraints": ["不得与冷硬或冷成形合并"]
}
```

至少应区分以下作用域：

- `product_name`：品名及材料状态。
- `process`：分条、分转平、直平、分段等加工方式。
- `packaging`：简包、密封包、木架等包装要求。
- `pricing`：卷价、`+N/-N`等计价表达。
- `specification`：`C`、丝、条、张、件、名义厚度等规格表达。
- `inventory`：原卷、回卷、预加工、现货、在途货等库存状态。
- `status`：没货、停产、延迟报价等业务状态。
