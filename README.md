> 使用原则：原始资料必须保留原文；标准词仅用于检索、匹配和目标系统输出。证据不足或存在业务差异时，不得自动替换。

## 3. 常用行业简称和业务黑话

这些词不是严格的同义词，但机器人需要理解其业务含义。

| 黑话或写法 | 建议解释 | 自动处理边界 |
|---|---|---|
| `厚度*宽度*C` | `C`表示卷材、长度不定，例如`1.5*175*C`。 | 只在规格末位使用此解释。 |
| `+170`、`+230简包价` | 在原卷价基础上的每吨加工/包装加价；“简包价”表示采用简包口径。 | 不得把`+N`当作完整销售价；币种和计价单位缺失时保留原文。 |
| 卷价、原卷价 | 加工母卷的基础单价。 | 与加工费、包装费、成品销售价分开。 |
| 分条 | 沿卷材长度方向纵向裁成目标宽度的窄条。 | 规格通常以`厚度*宽度`和“条”计数。 |
| 分转平 | 先分条，再平直/定尺剪板。 | 不能简化成单纯“分条”或单纯“平直”。 |
| 直平 | 原卷直接平直、定尺，不先分条。 | 与“分转平”工艺路径不同。 |
| 分段 | 把分条后的成品分成多个较小卷段。 | 应结合单卷重量、外径等要求。 |
| 一段过 | 不分段，连续成一个卷段。 | 已有明确同义日志证据。 |
| 双飞 | 特定分条排刀或生产方式。 | 日志仅出现2次，具体设备含义尚不足以自动展开，须向现场确认。 |
| 开、开料、开出 | 用指定原卷加工出目标规格和重量。 | “开N吨”通常是计划加工量，不一定等于最终成品磅重。 |
| 配料、配出、配到 | 选择适当原卷并计算能够加工出的目标重量。 | 不能把估算配出重量当作实际验收重量。 |
| 整卷用完 | 原卷全部投入本单加工，不留回卷。 | 仍需用实际用料和成品重量核对。 |
| 余下回卷 | 剩余原料重新成卷，不做预加工库存。 | 回卷包装方式必须另有明确说明。 |
| 余下开预加工 | 剩余材料加工成常备库存规格。 | 属于预加工，不等同于回卷。 |
| 不开预加工 | 剩余部分不转成预加工库存。 | 可能回卷或采用其他处理，必须结合上下文。 |
| 外采成品 | 不使用自有原卷加工，直接从外部采购目标成品。 | 不能读取千润内仓加工单来替代外采资料。 |
| 在途货 | 已采购或已确定资源、尚未正式入仓的材料。 | 不能当作当前现货库存。 |
| 低消5吨 | 最低加工量或最低计价量为5吨。 | 日志本身未区分“最低投料量”和“最低收费量”，应保留原文。 |
| 打外径 | 按卷外径要求分卷、成卷。 | 应同时保留“外径不超N米”等具体限制。 |
| 上木架、落木架、放木架 | 将成品放置在木架上交付。 | 木架是否自带、是否另计必须分别识别。 |
| 合打一包 | 多个规格或多组成品合并包装成一包。 | 不代表规格、重量或仓储号可以合并。 |
| 密封包 | 使用密封包装方式。 | 与简包不同，不能互相替代。 |
| 80锌 | 镀锌层级的行业简称。 | 是否表示双面合计`80g/㎡`，现有日志不足以确认，禁止擅自展开。 |
| `负公差15个C` | 很可能表示“负公差15丝”，约为`0.15mm`。 | 现有日志仅1次，且`C`可能是输入/OCR写法，必须人工确认。 |
| `1.48/1.49`按`1.5`、`1.98/1.99`按`2.0` | 名义厚度与现场/标签厚度的常见对应写法。 | 当前验收仅对成品规格按既定尾数规则进位；原料回卷必须保留原始厚度。 |
| `尾28/1.74/1504` | 头尾板28kg、实测厚度1.74、实测宽度1504。 | 只有“尾+明确数字”或其他受支持格式才能派生，不能猜测裸数字。 |
| `9115kg/1.48x1001/8kg` | 整卷重量9115kg、实测厚度1.48、实测宽度1001、头尾板8kg。 | 第一段不能误当成废料重量。 |
| 条 | 分条后的条带/小卷数量。 | 不等同于平板的“张”或包装的“件”。 |
| 张、件 | 平直/定尺板数量。 | 验收时与“条”对应不同加工区段。 |

## 4. 明确不能合并的近似词

| 容易误合并的词 | 实际区别 |
|---|---|
| 冷板、冷硬、冷成形 | 是不同产品状态/品类，不能统一成“冷板”。 |
| 普板、冷板 | 贸易日志中作为不同材料分别报价，不能视为同义词。 |
| 自由边、边丝 | 自由边是可利用余料；边丝通常是废料，验收分类不同。 |
| 简包、密封包 | 包装方式和费用口径不同。 |
| 回卷、预加工 | 回卷保留卷材；预加工是把余料加工成库存成品。 |
| 原卷价、`+N`加工加价、成品价 | 分别是材料基价、加工/包装增量和最终成品价格。 |
| 现货、在途货 | 现货当前可用；在途货尚未正式入仓。 |
| 分条、分转平、直平 | 三种不同加工路径，不能只按“都是加工”合并。 |
| SPCC、SPCC麻面、SPCC光面 | 验收目标输出可能去掉表面描述，但原始业务资料中的表面差异必须保留。 |
| `1.99`、`2.0` | 成品输出可按规则进位；原料和回卷不能因此改写。 |

## 5. 特别风险：字母 `C` 的语义重载

`C`至少存在两种完全不同的可能含义：

1. 规格末位：`1.5*175*C`中的`C`表示卷材。
2. 公差描述：`负公差15个C`中的`C`很可能是“丝”的输入或OCR写法。

因此禁止对字母`C`做全局替换；必须先判断它位于规格结构还是自然语言公差描述中。

## 6. 建议的词典数据结构

后续若将本词典用于程序，可为每组黑话保存以下字段：

```json
{
  "canonical": "冷板",
  "aliases": ["冷卷", "冷轧", "冷卷板", "冷轧卷板"],
  "scope": "product_name",
  "confidence": "high",
  "preserveOriginal": true,
  "constraints": ["不得与冷硬或冷成形合并"]
}
```

至少应区分以下作用域：

- `product_name`：品名及材料状态。
- `process`：分条、分转平、直平、分段等加工方式。
- `packaging`：简包、密封包、木架等包装要求。
- `pricing`：卷价、`+N`、过磅含税等计价表达。
- `specification`：`C`、条、张、件、名义厚度等规格表达。
- `inventory`：原卷、回卷、预加工、现货、在途货等库存状态。
